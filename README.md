# 💧 Consumo de Água

## 📌 Sobre o projeto

O **Consumo de Água** é um programa desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis.

O sistema considera o tipo de imóvel e o consumo mensal em metros cúbicos (m³) para apresentar uma mensagem de orientação ao morador.

### 🏠 Tipos de classificação

* 🏢 **Comercial:** apresenta uma mensagem sobre a tarifa comercial.
* 🏠 **Casa:** consumo de até 25 m³ é considerado moderado.
* 🏢 **Apartamento:** consumo menor que 10 m³ é considerado econômico.
* 💧 Consumos acima do limite residencial recebem um alerta para economia de água e verificação de possíveis vazamentos.

## ▶️ Como executar

1. Tenha o **Python** instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta `consumo-agua`.
4. Execute o arquivo `app.py`.
5. Informe o tipo de imóvel e o consumo mensal de água quando solicitado.

### 💻 Exemplo

```text
Digite o tipo de imóvel (1 - comercial, 2 - casa, 3 - apartamento): 3
Digite o consumo mensal de água em metros cúbicos (m³): 8

Seu consumo mensal de água é de 8.00 m³.
Consumo econômico - excelente controle de água!
```
